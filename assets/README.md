# Language strip sources

`languages-light.svg` and `languages-dark.svg` are monochrome compositions
for the repository README. Their geometry comes from these SVG sources:

- GNU Bash, Python, and Lua: [Simple Icons](https://github.com/simple-icons/simple-icons)
  at commit `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`
  (`icons/gnubash.svg`, `icons/python.svg`, `icons/lua.svg`).
- PowerShell: [PowerShell/PowerShell](https://github.com/PowerShell/PowerShell)
  at commit `edcbda3ae12dfdbce68f382572515c7bacde59b2`
  (`assets/ps_black_128.svg`).

The assets are used as language identifiers in documentation. The respective
names and marks belong to their owners.
