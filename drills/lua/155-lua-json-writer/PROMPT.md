# 155-lua-json-writer

> "The consumer of this report is a service that only speaks JSON, and the box has no JSON
> library on it. Write the report by hand. Last quarter somebody used the wrong quoting
> helper and the consumer fell over on a control character."

## Input

`in/records.tsv` — a header line `id\tname\tscore\tnote`, then one record per line, tab
separated:

```
id	name	score	note
1	Widget	3	plain
```

The export is messy: a note holds a quote and a backslash, another holds a tab and a bell
character, a name holds a non-ASCII letter, a score arrived as `0.30000000000000004`, and
one row is not a record at all. The file is generated by a setup script because it
carries raw control bytes.

## Rules

1. Skip the header. A record line holds at least **three tabs**. The first three
   tab-separated fields are `id`, `name` and `score`. The **note is everything after the
   third tab**, so a note may itself contain tabs. A line with fewer than three tabs is
   **invalid**.
2. `id` must be a decimal integer, `name` must be nonempty, and `score` must be a number.
   A record that breaks any of these is **invalid**. Invalid records are counted and
   contribute nothing to the report.
3. `note` is **null** when the field is empty. Otherwise it is a string.
4. **Numbers.** An integral score is written as an integer — `3`, never `3.0`. A
   fractional score is written with six significant digits: `2.5`, and
   `0.30000000000000004` becomes `0.3`.
5. **Strings.** A string must be written so that reading it back gives the same
   characters:
   - `"` and `\` are escaped with a backslash
   - a control byte (below `0x20`), such as a tab or a bell, is escaped — the JSON short
     escape (`\t`, `\b`, `\f`, `\n`, `\r`) or `\u00xx` with lowercase hex
   - everything else is written literally, including non-ASCII letters
6. The report is **one JSON object** with exactly three keys:
   - `records` — an array of the valid records, in input order, each an object with
     exactly the keys `id`, `name`, `score`, `note`
   - `count` — how many records are in `records`
   - `invalid` — how many records were invalid

## Output

Write exactly one file to `$OUT`:

**`out/report.json`** — the JSON object described above.

It must be **valid JSON**: no trailing comma, no comments, no `NaN`, and a control
character never appears literally inside a string. The file must parse as JSON in its
entirety.

## Messes to expect

- `has "quotes" and \ backslash` needs both escapes, and the backslash is escaped once,
  not twice
- `tab<TAB>and bell<BEL>` holds a tab and a bell inside the note; the note runs to the
  end of the line, so the tab inside it does not start a new field
- `Café` is written literally, not as `Caf\u00e9`
- the score `0.30000000000000004` must come out as `0.3`
- the empty `note` field is `null`, and the row whose `id` is not a number is invalid

## Timebox

Five minutes. Write the escaper one byte at a time. Do **not** use
`string.format("%q", s)` — that is Lua's own escaping and it is not JSON.
